API Documentation
1. AuthenticationController
Login
* Endpoint: /api/auth/login
* RequestBody: LoginDTO
   * Structure: { "usernameOrEmail": "...", "password": "..." }
   * e.g.:
{


  "usernameOrEmail": "john.doe",


  "password": "password123"


}


* Response: JwtResponse
   * e.g.:


{


  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",


  "type": "Bearer"


}

Get Profile
* Endpoint: /api/me/profile
* Response: UserSearchDTO
   * e.g.:


{


  "accountID": "a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11",


  "username": "john.doe",


  "email": "john.doe@example.com",


  "status": "ACTIVE",


  "role": "USER",


  "firstName": "John",


  "lastName": "Doe",


  "dateOfBirth": "1995-05-15",


  "country": "USA",


  "city": "New York",


  "address": "123 Main St",


  "organization": "Volunteer Org",


  "createdAt": "2023-10-27T10:00:00Z"


}
Update Profile
* Endpoint: /api/me/profile/update
* RequestBody: UserProfileUpdateDTO
   * Structure: { "email": "...", "firstName": "...", "lastName": "...", "dateOfBirth": "...", "country": "...", "city": "...", "address": "...", "organization": "..." }
   * e.g.:


{


  "email": "new.email@example.com",


  "firstName": "Johnny",


  "lastName": "Doe",


  "dateOfBirth": "1995-05-15",


  "country": "USA",


  "city": "San Francisco",


  "address": "456 Market St",


  "organization": "New Org"


}


* Response: Updated UserSearchDTO (Full structure as above)
Delete Profile
* Endpoint: /api/me/profile/delete
* RequestBody: AccountPasswordDTO
   * Structure: { "password": "..." }
   * e.g.:


{


  "password": "password123"


}


* Response: 204 No Content
Change Password
* Endpoint: /api/me/profile/change-password
* RequestBody: AccountPasswordChangeDTO
   * Structure: { "oldPassword": "...", "newPassword": "...", "confirmPassword": "..." }
   * e.g.:


{


  "oldPassword": "oldPassword123",


  "newPassword": "newPassword456",


  "confirmPassword": "newPassword456"


}


* Response: 204 No Content

4. AdminUserController
Create User
* Endpoint: /api/admin/users/create-user
* RequestBody: AccountAdminCreateDTO
   * Structure: { "username": "...", "password": "...", "confirmPassword": "...", "accountStatus": "...", "role": "...", "email": "..." }
   * e.g.:


{


  "username": "jane.smith",


  "password": "password123",


  "confirmPassword": "password123",


  "accountStatus": "ACTIVE",


  "role": "MANAGER",


  "email": "jane.smith@example.com"


}


* Response: UserSearchDTO (Full structure as in AccountProfileController)
Change User Role
* Endpoint: /api/admin/users/{id}/role
   * e.g.: /api/admin/users/a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11/role with a0eebc99... is id (UUID)
* RequestBody: AccountRoleUpdateDTO
   * Structure: { "role": "..." }
   * e.g.:


{


  "role": "ADMIN"


}


* Response: Updated UserSearchDTO
Change Account Status
* Endpoint: /api/admin/users/{id}/status
   * e.g.: /api/admin/users/a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11/status with a0eebc99... is id (UUID)
* RequestBody: AccountStatusUpdateDTO
   * Structure: { "status": "..." }
   * e.g.:


{


  "status": "BLOCKED"


}


* Response: Updated UserSearchDTO
Delete Account
* Endpoint: /api/admin/users/{id}/delete
   * e.g.: /api/admin/users/a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11/delete with a0eebc99... is id (UUID)
* Response: 204 No Content
Change User Password (Admin)
* Endpoint: /api/admin/users/{id}/change-password
   * e.g.: /api/admin/users/a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11/change-password with a0eebc99... is id (UUID)
* RequestBody: AccountAdminPasswordChangeDTO
   * Structure: { "newPassword": "...", "confirmPassword": "..." }
   * e.g.:


{


  "newPassword": "newAdminPassword123",


  "confirmPassword": "newAdminPassword123"


}


* Response: 204 No Content
Update User Details (Admin)
* Endpoint: /api/admin/users/{id}/update-details
   * e.g.: /api/admin/users/a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11/update-details with a0eebc99... is id (UUID)
* RequestBody: UserProfileUpdateDTO
   * Structure: { "email": "...", "firstName": "...", "lastName": "...", "dateOfBirth": "...", "country": "...", "city": "...", "address": "...", "organization": "..." }
   * e.g.:


{


  "firstName": "Jane",


  "lastName": "Smith Updated",


  "email": "jane.updated@example.com",


  "dateOfBirth": "1990-01-01",


  "country": "UK",


  "city": "London",


  "address": "Baker St",


  "organization": "Updated Org"


}


* Response: Updated UserSearchDTO
